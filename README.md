# LOISCOPE

LOISCOPE is a League of Legends analytics web application designed to analyze player performance using real match data from the Riot Games API.

The project retrieves player and match information and transforms it into useful performance metrics, helping players better understand their gameplay across different roles and regions.

## Features

- Search for League of Legends players by Riot ID
- Multi-region support
- Match history analysis
- Ranked Solo/Duo analysis
- Role-based performance filtering
- Kill Participation (KP)
- Damage per Minute
- CS per Minute
- Gold per Minute
- Vision analysis
- Objective participation
- Player performance statistics

## Technologies

- JavaScript
- Node.js
- Express.js
- HTML
- CSS
- Riot Games API
- REST APIs
- Git & GitHub

## How It Works

LOISCOPE uses a Node.js and Express backend to communicate with Riot Games APIs.

Player and match data is retrieved from Riot's API, processed by the application, and displayed through a custom web interface. The application also handles regional routing to support players from multiple League of Legends servers.

## Security

API credentials are stored using environment variables and are excluded from version control.

## Project Status

LOISCOPE is currently under active development. New analytics, performance insights, and improvements are being added as the project evolves.
